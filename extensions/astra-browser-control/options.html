Astra Browser Control

Connection

Must be ws:// or wss:// on localhost / 127.0.0.1.
Stored only in this browser's local extension storage. Sent once in the handshake to the saved origin.

Permissions

Leave empty to allow every http(s) page. The extension is installed manually and never acts on chrome:// or extension pages.
Saved ✓
This extension lets the local Astra server read and act on the pages you have open. Only pair it with a server on your own machine; the token is the access credential. Uninstalling or clearing the token immediately revokes access.
